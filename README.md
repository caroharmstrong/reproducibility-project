# reproducibility-project

Reproducibility Project for PSY 8960-003

This repository hosts my "Reproducible Workflow Project" for the course PSY 8960-003: Responsible Research Workflows (University of Minnesota, fall 2025, instructor: Moin Syed).

The goal of the project is to practice building a reproducible research project. The project's superficial goal is examining the association between neuroticism and loneliness among college students. 

Data were simulated to produce a mock pre-registration draft and are available within the "data" folder.

The final mock pre-registration draft is available as a PDF; its associated .Rmd file and other files are available within the "report" folder.
