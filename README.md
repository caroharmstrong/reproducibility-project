# reproducibility-project

This repository hosts my "Reproducible Workflow Project" for the course PSY 8960-003: Responsible Research Workflows (University of Minnesota, fall 2025, instructor: Moin Syed).

The goal of the project is for me to practice building a reproducible research project. The project's superficial goal is examining the association between neuroticism and loneliness among college students. 

Data were simulated to produce a mock pre-registration draft and are available within the "data" folder.

The final mock pre-registration draft is available as a PDF; it along with its associated .Rmd file and other files are available within the "report" folder. 

The file `.gitignore` serves the purpose of specifying to the GitHub/R communication line the names of any files that should *not* be uploaded to GitHub (e.g., excluding sensitive data from appearing on GitHub to preserve privacy); however, there is no sensitive data here or other reasons to exclude particular files, so there is nothing specified in the `.gitignore` file and it itself can be ignored. 

**For the most seamless experience reviewing or attempting to reproduce this project, please download the files in this repository as a ZIP by clicking the green "<> Code" button and then "Download Zip." Then, click on the file `reproducibility-project.Rproj` to open the R project before opening other files. (*Following these instructions should prevent file path problems from occurring*).**
